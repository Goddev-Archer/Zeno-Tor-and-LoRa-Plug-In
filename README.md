# 🛡️ Zeno Tor & LoRa Plugins

Offizielles Repository für funktionale Zensurschutz- und Off-Grid-Erweiterungen des dezentralen Zeno-Messengers.

---

## 📦 Enthaltene Plugins

| Plugin | Pfad | Beschreibung | Status |
| :--- | :--- | :--- | :---: |
| **🧅 Tor & Snowflake** | [`tor-snowflake/`](./tor-snowflake/) | WebRTC-Snowflake-Tunneling zur DPI-Umgehung & Tor-Relay-Anbindung | **Aktiv (v1.0.0)** |
| **📡 LoRa Funk-Mesh** | [`lora-mesh/`](./lora-mesh/) | Treiberfreie serielle Funkkommunikation via Web Serial API (868/433 MHz) | **Aktiv (v1.0.0)** |

---

## 🚀 Installation in Zeno

Kopiere den jeweiligen Ordner (`tor-snowflake` oder `lora-mesh`) in deinen lokalen Zeno-Plugin-Ordner:
- **Windows:** `%APPDATA%\zeno\plugins\`
- **Linux:** `~/.zeno/plugins/`
- **macOS:** `~/Library/Application Support/zeno/plugins/`

Oder installiere sie mit einem Klick über den Zeno-internen Community-Store!
